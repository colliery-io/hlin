{{- if eq .Values.config.auth.strategy "trusted-header" }}

Identity comes from the {{ .Values.config.auth.trustedHeader.header }} header,
which means the shell believes whatever that header says. Anything able to reach
a pod directly is therefore whoever it claims to be — and in a cluster a pod IP
is reachable from the rest of the namespace by default. An ingress in front is
not on its own enough: restrict what can reach these pods, with a NetworkPolicy
or a mesh.
{{- end }}

{{- if .Values.postgres.enabled }}

This release brought its own Postgres: a single pod with a volume, no
replication, no backups, no pooling. It is what makes a first install able to
do the thing Hlin is for — compose a surface, save it, send somebody the link
— rather than a degraded version of it. For anything whose loss would matter,
set postgres.enabled=false and point config.databaseUrlSecret at a database
you run.

  Its password is generated on install and kept in the Secret
  {{ include "hlin.fullname" . }}-postgres.
{{- else if .Values.config.databaseUrlSecret.name }}

The database comes from the Secret {{ .Values.config.databaseUrlSecret.name }},
read into the environment rather than written into a ConfigMap — a connection
string carries a password.
{{- end }}

{{- if not .Values.signingKey.existingSecret }}

The signing key will be generated on first start and kept on a volume. That is
correct for one replica. More than one needs signingKey.existingSecret, so they
share an issuer rather than being several — the chart will refuse the other
combination.
{{- end }}

{{- if not .Values.config.platforms }}

No platforms configured, so there are no panels to compose with yet. A platform
serves a manifest at /.well-known/hlin.json saying what it offers; add yours
under config.platforms:

  config:
    platforms:
      - id: your-platform
        baseUrl: https://your-platform.internal
        auth:
          strategy: hlin-token     # or `none`, for a platform that asks for nothing
{{- end }}

{{- if not .Values.config.frontendImage }}

Panels are drawn by the design pack this image was built with. To draw them
with your own, build a frontend against hlin-ui and put its `dist` in an image,
then set config.frontendImage — the shell will serve yours instead.
{{- end }}
